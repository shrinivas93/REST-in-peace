Getting started · rest-in-peace + rest-in-peace-spring-boot-starter

One client interface, every way to wire it up.

Every feature below works identically no matter how the client was constructed — a JDK dynamic proxy, a compile-time-generated class, or a Spring bean all resolve through the same RIP.getClient(...) choke point. What differs is how you configure and inject the client. Each entry shows the plain-Java form first, then every documented alternative — a different overload, a default, a collection form, or the Spring Boot starter's own way of expressing the same thing.

Amber snippets run in plain Java (or any JVM language). Green snippets are specific to the rest-in-peace-spring-boot-starter module. See the README for Maven/Gradle coordinates and the Javadoc for the full API surface.

Declaring a client

Every client starts as an annotated interface. Where its base URL comes from is the first thing that varies by environment — and by whether Spring is involved.

@RestClient + @BaseUrl

A fixed base URL, known at compile time. Methods write relative paths against it.

Basic
@RestClient
@BaseUrl("https://api.example.com")
interface UserApi {
    @GET("/users/{id}")
    User getUser(@PathParam("id") String id);
}

UserApi api = RIP.getClient(UserApi.class);

Base URL resolved at runtime

@BaseUrl must be a compile-time constant, so an env-dependent host bypasses it entirely.

Alternate · env var wins over @BaseUrl
@RestClient
interface UserApi {
    @GET("/users/{id}")
    User getUser(@PathParam("id") String id);
}

UserApi api = RIP.getClient(UserApi.class, System.getenv("USER_API_BASE_URL"));
Alternate · full config base URL + timeout + proxy together
UserApi prodApi = RIP.getClient(UserApi.class, RipClientConfig.builder()
        .baseUrl(prodBaseUrl)
        .connectTimeoutMillis(2_000)
        .readTimeoutMillis(10_000)
        .build());
Spring · property-resolved
@RestClient(baseUrlProperty = "user-api.base-url")
interface UserApi {
    @GET("/users/{id}")
    User getUser(@PathParam("id") String id);
}
user-api:
  base-url: https://api.example.com
@SpringBootApplication
@EnableRestInPeaceClients
class Application { }

@Service
class Orders {
    Orders(UserApi userApi) { ... }   // injected — zero @Bean method
}

HTTP methods & URLs

One verb annotation per method, plus two ways to build the URL a request hits.

Method annotations

Exactly one of @GET @POST @PUT @PATCH @DELETE @HEAD @OPTIONS per method — none or more than one fails validation.

Basic
@GET("https://api.example.com/items/{id}")
String getItem(@PathParam("id") String id);

@DELETE("https://api.example.com/items/{id}")
void deleteItem(@PathParam("id") String id);

@PathParam

Fills a {placeholder} in the URL. Values are percent-encoded, so a stray / or ? never breaks the route.

Basic
@GET("https://api.example.com/items/{id}")
String getItem(@PathParam("id") String id);

@Url

For a URL that isn't a fixed template — a pagination next link, a HATEOAS action link.

Basic · pagination
@GET
Page nextPage(@Url String url);

Page page = itemApi.firstPage();
while (page.next != null) {
    page = itemApi.nextPage(page.next);
    process(page.items);
}

Query params & headers

Fixed-by-name params, open-ended maps for names known only at runtime, and headers that never change.

@QueryParam / @HeaderParam

required throws at call time with no value; defaultValue fills in for null.

Basic · required + default
@GET("https://api.example.com/items")
String search(@QueryParam(value = "q", required = true) String query,
               @QueryParam(value = "page", defaultValue = "1") Integer page);
Alternate · collection repeats ?tag=a&tag=b
@GET("https://api.example.com/items")
String search(@QueryParam("tag") List tags);
Alternate · header
@GET("https://api.example.com/items")
String search(@HeaderParam(value = "Authorization", required = true) String token);

@QueryMap / @HeaderMap

For names not known until runtime — an open-ended filter set, caller-supplied headers. One entry becomes one param; null entries are skipped, not thrown.

Basic · dynamic filters
@GET("https://api.example.com/search")
String search(@QueryParam("q") String query, @QueryMap Map filters);
Alternate · dynamic headers
@GET("https://api.example.com/users/{id}")
User getUser(@PathParam("id") String id, @HeaderMap Map extraHeaders);

@Headers

Fixed headers that are always the same value — split on the first :, whitespace trimmed.

Basic @HeaderParam/@HeaderMap wins on a name clash
@GET("https://api.example.com/users")
@Headers({ "Cache-Control: no-cache", "X-Api-Version: 2" })
List listUsers();

Request bodies

Three mutually-exclusive body encodings — JSON/raw, multipart, and form-urlencoded — each valid only on POST/PUT/PATCH/DELETE.

@Body

A String goes as-is; anything else is JSON-serialized.

Basic · POJO
@POST("https://api.example.com/items")
String createItem(@Body Item item);
Alternate · raw JSON string
@POST("https://api.example.com/items/raw")
String createRaw(@Body String rawJson);

@Multipart / @Part / @PartMap

File uploads and classic form POSTs. File, byte[], and InputStream parts all become file parts; a plain String becomes a form field.

Basic · fixed parts
@POST("https://api.example.com/users/{id}/avatar")
@Multipart
String uploadAvatar(@PathParam("id") String id,
        @Part("caption") String caption, @Part("file") File avatar);
Alternate · byte[] needs a filename
@POST("https://api.example.com/users/{id}/avatar")
@Multipart
String uploadAvatarBytes(@PathParam("id") String id,
        @Part(value = "file", fileName = "avatar.png") byte[] avatarBytes);
Alternate · dynamic parts
@POST("https://api.example.com/uploads")
@Multipart
String upload(@PartMap Map parts);

Map parts = new LinkedHashMap<>();
parts.put("caption", "vacation photo");                    // plain field
parts.put("thumb", photoBytes);                             // filename defaults to "thumb"
parts.put("file", PartValue.of(photoBytes, "photo.jpg"));   // explicit filename
api.upload(parts);
Alternate · progress
@POST("https://api.example.com/users/{id}/avatar")
@Multipart
String uploadAvatar(@PathParam("id") String id, @Part("file") File avatar,
        UploadProgressListener onProgress);

api.uploadAvatar("42", avatar, (field, sent, total) ->
        System.out.printf("%s: %d / %d%n", field, sent, total));

@FormUrlEncoded / @Field / @FieldMap

OAuth token endpoints and classic HTML forms — application/x-www-form-urlencoded, not JSON.

Basic
@POST("https://api.example.com/oauth/token")
@FormUrlEncoded
String getToken(@Field("grant_type") String grantType, @Field("client_id") String clientId);
Alternate · dynamic fields
@POST("https://api.example.com/search")
@FormUrlEncoded
String search(@FieldMap Map filters);

Return types

The declared return type is the whole decoding contract — no separate converter registration.

String / POJO / void

Basic · all three
@GET("https://api.example.com/users/{id}")
String getUserRaw(@PathParam("id") String id);   // raw response body

@GET("https://api.example.com/users/{id}")
User getUser(@PathParam("id") String id);        // JSON deserialized into User

@POST("https://api.example.com/events")
void fireEvent(@Body Event event);               // response discarded

Binary downloads: byte[] and File

byte[] buffers the whole response; File streams straight to disk for large payloads.

Basic · byte[]
@GET("https://api.example.com/reports/{id}/pdf")
byte[] downloadReport(@PathParam("id") String id);
Alternate · streamed to File
@GET("https://api.example.com/reports/{id}/pdf")
File downloadReport(@PathParam("id") String id, @Destination File target);

File pdf = reportApi.downloadReport("42", new File("/tmp/report.pdf"));
Alternate · progress
@GET("https://api.example.com/reports/{id}/pdf")
File downloadReport(@PathParam("id") String id, @Destination File target,
        DownloadProgressListener onProgress);

reportApi.downloadReport("42", target, (sent, total) ->
        System.out.printf("%d / %d%n", sent, total));   // total is -1 with no Content-Length

RipResponse<T>

When a call needs the status code or a header too, not just the body.

Basic
@GET("https://api.example.com/users/{id}")
RipResponse getUser(@PathParam("id") String id);

RipResponse response = userApi.getUser("42");
response.getStatus();               // 200
response.getHeader("ETag");         // first value, case-insensitive
response.getHeaders();              // Map>
User user = response.getBody();

Async — CompletableFuture<T>

Same decoding rules as a synchronous T, just non-blocking. Combines with byte[], File, and RipResponse<T> too.

Basic
@GET("https://api.example.com/users/{id}")
CompletableFuture getUserAsync(@PathParam("id") String id);

userApi.getUserAsync("42").thenAccept(user -> System.out.println(user.name));
Alternate · keep the JVM exiting not the default — reconfigures the shared client
RIP.useDaemonThreadsForAsync();   // call once at startup, before any async call
Spring · default flipped called for you, unconditionally, at context startup
// A long-running Spring app has no reason to want non-daemon I/O threads
// outliving its own shutdown — the starter's auto-configuration calls
// RIP.useDaemonThreadsForAsync() automatically. No property to opt out;
// exclude RestInPeaceAutoConfiguration if you truly need the plain-Java default.

Error handling & resilience

A non-2xx response always throws; retries and timeouts are declared per method.

RestInPeaceHttpException / @ErrorType

Basic · raw error body
try {
    User user = userApi.getUser("42");
} catch (RestInPeaceHttpException e) {
    e.getStatus();     // 404
    e.getRawBody();    // always available
}
Alternate · typed error body
@GET("/users/{id}")
@ErrorType(ApiError.class)
User getUser(@PathParam("id") String id);

catch (RestInPeaceHttpException e) {
    ApiError error = e.getErrorBody();   // deserialized, not raw
    System.out.println(error.code);
}

@Retry & idempotency keys

Retries on transport errors or a configurable status set; idempotent=true makes retrying a POST safe too.

Basic default retryOnStatus: 429, 502, 503, 504
@GET("https://api.example.com/users/{id}")
@Retry(times = 3, delayMillis = 200, backoffMultiplier = 2.0)
User getUser(@PathParam("id") String id);
Alternate · fixed delay
@Retry(times = 3, delayMillis = 500, backoffMultiplier = 1.0)   // no exponential backoff
Alternate · safe retry for POST one Idempotency-Key header, identical across attempts
@POST("https://api.example.com/charges")
@Retry(times = 3, delayMillis = 200, idempotent = true)
String createCharge(@Body Charge charge);

@Timeout

Overrides connect/read timeout for one method only. Priority: @Timeout > RipClientConfig > shared client default.

Basic
@GET("https://api.example.com/reports/export")
@Timeout(readMillis = 120_000)
String exportReport();

Client configuration

Everything one client's environment can differ in — base URL, timeout, proxy, JSON mapper, cache, interceptors — lives on RipClientConfig.

RipClientConfig.builder()

Setting a timeout, proxy, or objectMapper gives the client its own connection pool instead of sharing the app-wide one.

Basic · full builder
UserApi prodApi = RIP.getClient(UserApi.class, RipClientConfig.builder()
        .baseUrl(prodBaseUrl)
        .connectTimeoutMillis(2_000)
        .readTimeoutMillis(10_000)
        .proxy("proxy.example.com", 8080)                 // or proxy(host, port, user, pass)
        .objectMapper(new JacksonObjectMapper(myMapper))
        .build());
Spring · YAML-bound no @Bean method — resolved per client by name
rest-in-peace:
  clients:
    user-api:                 # @RestClient(name = "user-api"), or the
                               # decapitalized interface name by default
      connect-timeout-millis: 2000
      read-timeout-millis: 10000
      proxy: { host: proxy.example.com, port: 8080 }

JSON ObjectMapper

Gson-backed by default. Swap it app-wide, or per client.

Basic · shared default every client sharing the static Unirest client
RIP.setObjectMapper(new JacksonObjectMapper(myJacksonMapper));   // once, at startup
Alternate · one client's own RIP.setObjectMapper has no effect on this one
RipClientConfig.builder().objectMapper(new JacksonObjectMapper(myMapper)).build();
Spring · by bean, qualified or shared
@Bean
@Qualifier("user-api")           // wired only into the user-api client
ObjectMapper userApiMapper() { return new JacksonObjectMapper(myMapper); }

@Bean                            // unqualified — used as the shared default
ObjectMapper sharedMapper() { return new JacksonObjectMapper(myMapper); }
// ^ only applies when it's the single unqualified bean of that type

Response caching

Honors Cache-Control/ETag/Last-Modified — never invents caching the server didn't ask for. GET/POJO only, for now.

Cache — shared, per-client, or a bean

Basic · shared default
RIP.setCache(new InMemoryCache());   // ConcurrentHashMap-backed, ships free
Alternate · one client's own
UserApi api = RIP.getClient(UserApi.class,
        RipClientConfig.builder().cache(new InMemoryCache()).build());

// Or back it with Redis / Caffeine / anything else:
class RedisCache implements Cache {
    public CachedResponse get(String key) { ... }
    public void put(String key, CachedResponse r) { ... }
    public void evict(String key) { ... }
    public void clear() { ... }
}
Alternate · opt one method out
@GET("https://api.example.com/prices/{symbol}")
@NoCache
Price getLivePrice(@PathParam("symbol") String symbol);
Spring · qualified or shared bean
@Bean
@Qualifier("user-api")
Cache userApiCache() { return new InMemoryCache(); }

Interceptors

"Onion" ordering: global beforeRequest runs first, global afterResponse runs last — global interceptors bracket every per-client one.

Global vs. per-client

Basic · global, every client
RIP.addInterceptor(new RequestInterceptor() {
    public void beforeRequest(RequestContext ctx) {
        ctx.addHeader("Authorization", "Bearer " + currentToken());
    }
    public void afterResponse(RequestContext ctx, int status, Object body) {
        System.out.println(ctx.getHttpMethod() + " " + ctx.getUrl() + " -> " + status);
    }
});

RIP.clearInterceptors();   // removes everything registered
Alternate · scoped to one client
StripeApi stripe = RIP.getClient(StripeApi.class, RipClientConfig.builder()
        .baseUrl("https://api.stripe.com")
        .interceptors(List.of(new HeaderInterceptor("Authorization", () -> "Bearer " + stripeKey)))
        .build());
Spring · qualifier decides scope unqualified → global; qualified → that one client
@Bean                              // no @Qualifier — registered globally at startup
RequestInterceptor authInterceptor() {
    return new HeaderInterceptor("Authorization", () -> "Bearer " + currentToken());
}

@Bean
@Qualifier("stripe-api")           // wired only into the stripe-api client's own config
RequestInterceptor stripeAuth() { ... }

Pre-built interceptors

Registered exactly like a hand-written one — plain Java shown; each also works as a @Bean in Spring, qualified or not.

HeaderInterceptor fixed, Supplier, or a map of either
RIP.addInterceptor(new HeaderInterceptor("Authorization", "Bearer " + token));      // fixed value
RIP.addInterceptor(new HeaderInterceptor("Authorization", () -> currentToken()));    // re-evaluated per call
RIP.addInterceptor(HeaderInterceptor.of(Map.of("X-Api-Key", "abc123")));             // several at once
RIP.addInterceptor(new HeaderInterceptor(Map.of("Authorization", () -> currentToken())));
LoggingInterceptor
RIP.addInterceptor(new LoggingInterceptor());                 // to System.out
RIP.addInterceptor(new LoggingInterceptor(logger::info));     // or your own sink
CorrelationIdInterceptor
RIP.addInterceptor(new CorrelationIdInterceptor());                                // random UUID, X-Request-Id
RIP.addInterceptor(new CorrelationIdInterceptor("X-Trace-Id", () -> traceIdGenerator.next()));
MetricsInterceptor one sample per attempt, incl. retries
RIP.addInterceptor(new MetricsInterceptor((method, url, status, ms) ->
        System.out.printf("%s %s -> %d (%dms)%n", method, url, status, ms)));

Compile-time proxies & testing

Two things that happen underneath the interface, without changing how you call it.

Compile-time proxy generation

No opt-in — a supported method shape gets a real generated <Interface>_RipImpl class automatically; anything else falls back to the reflective proxy, transparently.

Zero code change same call site either way
UserApi api = RIP.getClient(UserApi.class);
// api.getClass() is UserApi_RipImpl        — supported shape, reflection-free
// api.getClass() is a java.lang.reflect.Proxy — unsupported shape, same behavior

MockRestServer

A real local HTTP server — @Retry, @Timeout, and every interceptor run completely unmodified against it.

Basic · manual lifecycle
MockRestServer server = MockRestServer.start();
server.on(HTTPMethod.GET, "/orders/{id}", MockResponse.json(new Order("42", "shipped")));

OrderApi api = RIP.getClient(OrderApi.class, server.baseUrl());
assertEquals("shipped", api.getOrder("42").status);
assertEquals(1, server.countOf(HTTPMethod.GET, "/orders/{id}"));
server.close();
Alternate · JUnit 5 extension no Spring context needed at all
@ExtendWith(MockRestServerExtension.class)
class OrderApiTest {
    @Test
    void getOrder_returnsDecodedBody(MockRestServer server) {
        server.on(HTTPMethod.GET, "/orders/{id}", MockResponse.json(new Order("42", "shipped")));
        OrderApi api = RIP.getClient(OrderApi.class, server.baseUrl());
        assertEquals("shipped", api.getOrder("42").status);
    }
}
Alternate · prove @Retry recovers
server.onFlaky(HTTPMethod.GET, "/orders/{id}", 2,
        MockResponse.status(503, ""), MockResponse.json(new Order("42", "shipped")));

Order order = orderApiWithRetry.getOrder("42");   // succeeds on the 3rd attempt
Spring · @AutoConfigureMockRestServer redirects every registered client's base URL for you
@SpringBootTest
@AutoConfigureMockRestServer
class UserServiceTest {
    @Autowired MockRestServer server;
    @Autowired UserApi userApi;   // already pointed at server.baseUrl()

    @Test
    void getUser_returnsDecodedBody() {
        server.on(HTTPMethod.GET, "/users/{id}", MockResponse.json(new User("42", "Shrinivas")));
        assertEquals("Shrinivas", userApi.getUser("42").name);
    }
}

Java, Spring, Kotlin

The construction site is the one place plain Java and Spring genuinely diverge — everything above is identical once you have a client instance.

Plain Java, CLI tools, scripts

Basic · construct once, reuse
public final class Clients {
    public static final UserApi USER_API = RIP.getClient(UserApi.class);
    private Clients() {}
}

Spring — two ways to wire a bean

Spring Boot starter 4.x, Java 17+ — zero hand-written @Bean method
@SpringBootApplication
@EnableRestInPeaceClients
class Application { }

@RestClient(baseUrlProperty = "user-api.base-url")
interface UserApi {
    @GET("/users/{id}")
    User getUser(@PathParam("id") String id);
}
Alternate · hand-written @Bean Spring on older Java, or anywhere you'd rather not scan
@Configuration
class RipClientsConfig {
    @Bean
    UserApi userApi(@Value("${user-api.base-url}") String baseUrl) {
        return RIP.getClient(UserApi.class, baseUrl);
    }

    @Bean
    StripeApi stripeApi(@Value("${stripe.api-key}") String apiKey) {
        return RIP.getClient(StripeApi.class, RipClientConfig.builder()
                .baseUrl("https://api.stripe.com")
                .connectTimeoutMillis(2_000)
                .interceptors(List.of(new HeaderInterceptor("Authorization", () -> "Bearer " + apiKey)))
                .build());
    }
}
